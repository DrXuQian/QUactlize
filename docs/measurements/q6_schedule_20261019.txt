lane ownership and32/64/128-byte footprints. Duplicate source reads do not
equal DRAM traffic; eight tokens in the focus reuse the same expert weights.

partial reduction association, so all six arms independently pass the same
unchanged GGUF oracle. All changed-input, large-BF16, zero-A, poisoned output,
low/high/metadata negative, copy isolation and guard checks remain enabled.

How to test
-----------
Use tools/run_q6_schedule_box.sh on one otherwise idle PPU. It archives the
local pinned git objects, never fetches nested HTTPS submodules, and compiles
only the bounded experiment (both activation precisions). POINTS=0 is the
default; POINTS=all adds the seven existing numerical/event controls. It does
not expand the profiled focus or claim multi-shape cycle admission.

One independent numerical/cold-ring timing phase, then18 ACU captures:
0,1,2,3,4,5 / 5,4,3,2,1,0 / 0,1,2,3,4,5.
Each capture has one weight copy, one direct selected kernel, no graphs and
no cold-ring loops; cache-control=all. Cold event timings are separate and
secondary. First-use graph upload/JIT/fixture creation are excluded.

Output comparisons:0/1 and0/2 (warps),0/3,1/4,2/5 (pipeline).
Rank by median CE elapsed cycles, never frequency-derived microseconds or
opcode counts. Require matching CE/CU/PU/memory clocks and consistent pair
direction; differing clocks, mixed pairs, missing/duplicate reports or wrong
geometry cannot certify a win. fastest_measured_arm is just a ranked result,
not a promotion; performance_admitted=false and production_changed=false.
All logs and actual reports go into the printed results/review.tgz, excluding
the generated object/DSO payloads. Valid independent results survive failures.

Scope at handoff: host tests and local codegen verified; device precision,
CE cycle gain and model TPOT are NOT_RUN. Do not replace production routing.
