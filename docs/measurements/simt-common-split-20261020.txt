Production boundary
  simt_common.cuh carries the same tested metadata/address/body.
  simt_common_scope.hpp shares eligibility with codegen and explain.
  No shape-to-config selection, public ABI, canonical format, rounding,
  reducer, caller or Q8 production change. Unmeasured geometries/storage
  keep their old implementation. The F32 endpoints retain both compute types.
  New shapes within these generic geometry contracts use the common body;
  no measured speed claim is made for an unseen shape.
  Existing fused gate-up bodies are unchanged, not covered by this promotion.
  Public launch code routes eligible calls to common before the old fallback.
  Native-port gate compares actual production kernels with the measured
  producer (both precisions, every admitted geometry/mode), requiring byte
  equality and zero stack. Local compiler gate is not fresh device evidence.
