Read/ownership contract
-----------------------
For C4, g=warp*8+lane/4+iteration*64. Each active warp owns8 consecutive
groups within one32-group/36-byte unit. Owner column lane=(lane%4)*8+p;
its group may differ from the receiving lane, so extract fields using the
RECEIVER'S group after exchange, not the source lane's group.
Required uint32 words by phase (g>>3)&3:
  0:0,1,2; 1:0,2,3,4; 2:4,5,6; 3:4,7,8.
A2 loads3/4 words instead of9. It always shuffles four named registers,
zero-filling an unused fourth field, to avoid masked-shuffle reconvergence.
Both code planes and A retain identical addresses. Metadata lane stride is
36 bytes; source32/64/128-byte footprints are recorded for every warp and
actual plane-base alignment. These are request models, not DRAM counters.

A2 metadata lowering uses a b32x2 load plus a b32 load in phases0/2/3,
and b32x2 plus two b32 loads in phase1, rather than two b32x4 plus b32.
There are four phase paths, so summing STATIC global-load sites over all
paths would overcount per-warp execution. Numerical equivalence does not
prove performance. Register-limited occupancy does not improve here.

Rejected local draft: conditionally exchanging the fourth register added
masked-shuffle control flow; static BF16 sites remained2290. The fixed-four
variant plus straight-line field selection reduced sites to2130. This is
a code-generation decision, NOT a measured speedup or GPU correctness pass.

Box contract
------------
tools/run_q6_sparse_box.sh defaults to one focus point0, one configuration,
two arms, six alternating timing rounds x five samples. It rebuilds only
the narrow F16/BF16 experimental modules, not llama or the production .so.
Existing independent GGUF dot, RAW equality, changed inputs, BF16 large-range
inputs, zero-A, plane/copy negative controls and guards remain mandatory.
Ordinary event timing uses the existing>=2.25L2 active-weight ring. Separate
ACU profiles only A2 with one weight copy and graph-profiling=none; it never
runs the cold timing loop under ACU. Warmup and first use remain excluded.
POINTS=all enables the original eight controls after the focus experiment.
PROFILE_ACU=0 runs numerical and paired timing only.
Upload the printed results/review.tgz (JSON/logs/native text/ACU only).

NOT_RUN until the new paired Box results are reviewed.
