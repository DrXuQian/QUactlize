================================

Purpose: remeasure configuration ranking after the historical 1.0 GHz cohort
changed to 1.7 GHz, including the admitted common Q2..Q6 SIMT implementation
and the scoped Q8 signed-address/window candidates. Never scale or reuse old

Frozen workload denominator: 1114 prior decode points, 530 dense / 584 indexed,
104 weight families. Existing M1..8 workload/precision/router contracts are
retained. This is not every possible shape or a new larger-M campaign.
Old component/canonical C++ incumbents are mandatory comparisons. Historical
same-fixture near winners and nearest legal TC route representatives seed a
bounded pool; timing values only rank that old fixture's recipes. Common SIMT
uses its admitted 3/4 geometries and legal S1/2/4/8. No tile/stage Cartesian
product. Current plan: 22743 arms, at most28/point,70 TC and176 vector modules.
This explicitly includes historical recipes, NOT a blind fallback-recall test.

Q8 extra bodies: original-hoisted experimental control, signed2D, signed
pointer induction, half-window and combined; two geometries, denseS1 only.
The actual production incumbent still uses its real measured-body dispatch,
not a slower generic substitute. Both ordinary and new Q8 candidates remain
eligible; no blanket half-window promotion. New MoE/Split-K Q8 bodies are not
claimed. Their existing shipping SIMT/TC alternatives are remeasured.

One shared compilation stage precedes all timing. Compiler concurrency is
bounded by available memory and JOBS;192 requested jobs is not192 busy cores.
Whole families stay on one physical card, with no cross-card A/B pair.
Source, SDK, actual device, module images, plan and shard ownership are sealed.
Before timing the runner requests min=max1700MHz on each assigned physical
PCI device with PPU-SMI --lock-ppu-clocks=1700,1700 --error-on-warning.
Only CU clock settings change; no memory-clock, power-limit or device reset.
The requested setting is left in place after the run (not automatically reset).
Cards must otherwise be idle. PLAN_ONLY/BUILD_ONLY do not set clocks.

User-directed update2026-10-20: after a successful lock request, actual
CU/memory frequencies are diagnostic ONLY. Lower clocks do not fail a point,

Read-only current-clock observations run outside each timing round; they

Every arm passes independent GGUF full-output oracle, changed input, plane
pointer negatives, zero/omitted-producer checks, guard regions and extracted
sequence replay. BF16 retains large finite inputs. Unsupported resource queries
are explicitly reported, not measured losses; missing incumbents block a point.

Six alternating rounds x five samples; producer, reducer, adapters and SF
expansion are separate single-kernel event timers. Helpers are deduplicated by
their full semantics within a point. Producers rotate >=2.25x verified L2;
SF gets its independent metadata-only ring. No mixed three-kernel timer or
estimated launch penalty. First graph upload/warmup is excluded.
Selection uses measured component sums, NOT measured model TPOT.

No ACU capture. No wall-time deadline/automatic24h kill. The displayed ETA uses
recent completed point wall time on the slowest worker; it excludes unseen
fixture overhead and is explicitly not a guarantee. Do not project duration
from microsecond kernel costs. Successful per-point receipts survive resume.
Each failed child exits; another process continues unrelated points. A new
invocation retries failed/missing points, never relabels them successful.
