Contract: retain the minimum confirmed complete-call configuration for each
measured request and its actual implementation, not merely an equal-looking
geometry tuple. Dense F32 endpoints/F16 compute and indexed F32 endpoints/BF16
compute remain separate. Canonical and paired-N4 layouts are not interchangeable.

   Asys. Selection/minimum reconciliation is local; do not repeat its sweep.
   Do not claim device integration before this run.
