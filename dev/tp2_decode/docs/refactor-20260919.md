# Selection refactor work record

Baseline: `5168b7136c40434bef01b6ac48732b0cce5468a1`.
Branch: `dev/dispatch-refactor`; no external reviewer or secondary agent.
Existing fallback gate and artifact remain immutable at their old source.

The requested implementation follows a direct source review. Scope is the
host decision/packaging boundary, not a new performance policy or changed
device arithmetic. Preserve canonical layouts, public C ABI, precision,
old measured exceptions, unresolved exclusions, bounded donor choice and
complete-call cost semantics. Do not remove a winning TC in favor of SIMT.

Planned work, in order:

1. Capture the previous final small-M decision, including Q8 overlays, using
   an independent test-only oracle; exercise exact/bucket/excluded/invalid,
   all formats/compute types and actual TP2 points. Keep C ABI TC ticket tests.
2. Create one pure final selector. Fold static replacement records at build
   time; preserve the original donor eligibility/tie-breaking. Separate
   host selection from module materialization, with named cache context.
3. Use the same selector for typed build/prewarm requests; keep the legacy
   fixed-route planner compatible for component experiments. Validate exact
   SIMT inventory coverage rather than only presence of variant numbers.
4. Make timed implementation identity (dynamic/fixed/hoist/reducer) explicit
   and test it without changing device launch bodies. Preserve fusion as a
   separate operator scope, not an equivalent ordinary projection.
5. Run host equivalence/regressions, SDK narrow compile/native inspection,
   rebuild the small dispatcher/component gate and publish one source-matched
   box handoff. Device correctness/performance remains pending until returned.

## Implemented and checked locally

The selector, effective replacements, typed planning, capability checks and
named cache context are implemented. `binding.cpp` now materializes a selected
TC without owning another selection policy. The old Q8 overlay implementation
was moved to a test-only oracle; no product caller includes it.

- Public C ABI snapshot against the immutable baseline: **13,007 requests**
  identical, including errors, donors, workspace and TC tickets. Coverage
  includes exact, neighbor/bucket, exclusions, invalid contracts and TP2 M1..8.
- Launcher strategy comparison: **1,990,656 combinations**, identical to the
  old guarded host branches. This is not device numerical evidence.
- Local regression suites: **234 passed**. This includes module identity,
  JIT-only-on-miss, capture/run lifecycle, BF16 metadata, graph/alias contracts,
  weak alignment, resume and profiler-denominator checks.
- Actual generated execution inventory covers **189 typed SIMT recipes**, the
  Q4 reader and **62 typed TC parents** selected by the exact catalog. The TC
  parents remain separate F16/BF16 and dense/grouped endpoint identities.
- An all-SIMT typed prewarm plan performs zero kernel compilations and needs no
  SDK access. A plan with a policy miss cannot be labelled complete.
- Narrow PPU compile passed. **69 emitted instances / 54 unique kernels** have
  identical instruction bytes/operands and identical resources versus the
  pre-refactor fallback build. Normalized instruction digest:
  `28d1e86143f4fc2b3e9340e2c1de42137bdaabdf99f8524abf0d1de68320ab49`.

## One device boundary

`tools/run_decode_fallback_box.sh` and `fallback_prebuilt.json` identify the
combined source-matched handoff. The gate calls the full production execution
C ABI, retains the previous confirmed minimum for each known point, checks
M1..8 numerics and then M1 cold complete-call timing/ACU. Prepare shape/router/
alias checks run in the same command. Failed independent points are retained
and resumable; no runtime is installed and no winner is promoted automatically.

Device correctness/performance is **pending**. Full-model TPOT/Asys follows
component admission; this gate must not be called an end-to-end model result.
Large MoE lifecycle code is not split into additional layers for cosmetic
reasons. Promoting new measured TP2 winners is separate from this behavior-
preserving refactor.
